# B8A1 - Problem Solving with TypeScript & OOP

## About This Assignment

This assignment is about learning TypeScript and Object-Oriented Programming (OOP). It helped me understand important TypeScript concepts and improve my problem-solving skills.

## Technologies Used

- TypeScript
- JavaScript
- Object-Oriented Programming (OOP)
- Git and GitHub

## Problems Solved

I solved 8 problems using TypeScript.

1. Function with Default Parameters
2. Union Types and Type Narrowing
3. Readonly Tuple
4. Generic Rest Parameters
5. Interface and Array Filtering
6. Generics with keyof
7. Classes and Inheritance
8. Promise and Asynchronous Programming

## What I Learned

- How to use TypeScript types.
- How to work with optional and default parameters.
- How to use union types and type narrowing.
- How to create and use interfaces.
- How to work with generics.
- How to use classes and inheritance.
- How to use public, private, and protected members.
- How to work with Promises and asynchronous functions.
